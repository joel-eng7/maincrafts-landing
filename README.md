# MainCrafts — Full Stack Web Development Internship (Task 1)

> **Build Smarter. Create Without Limits.**  
> A premium, portfolio-grade, futuristic technology startup landing page engineered with semantic HTML5, modern CSS3, and vanilla JavaScript.

---

## 🌟 Project Overview

This project was built for **MainCrafts Full Stack Web Development Internship – Task 1**. The objective is to design and develop an award-winning, production-ready landing page that looks and functions like a modern high-growth tech startup.

It avoids generic templates, basic beginner HTML layouts, and unnecessary heavy dependencies by utilizing pure modern web standards with pixel-perfect attention to typography, responsive layouts, glassmorphism, and micro-interactions.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic document structure, accessibility landmarks, ARIA attributes.
- **CSS3**: CSS Custom Properties (Variables), Flexbox, CSS Grid, clamp-based fluid typography, keyframe animations, glassmorphism.
- **Vanilla JavaScript (ES6+)**: Zero framework bloat, `IntersectionObserver` for scroll reveals and number counters, interactive modals, responsive drawer, canvas particle system, and form validation.
- **Google Fonts**: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) (Headlines), [Inter](https://fonts.google.com/specimen/Inter) (Body copy), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) (Code & metrics).
- **Icons**: Font Awesome 6 + custom crisp SVG brand icons.

## 🚀 Sections & Features

1. **Sticky Navigation Header**:
   - Initial transparent state transitioning smoothly to a dark glassmorphic blur on scroll (`.scrolled`).
   - Custom SVG brand mark with glowing gradient.
   - Fully functional **Services Dropdown Menu** with dedicated icons and descriptions that smoothly scrolls to the chosen service with a highlighted border pulse.
   - Mobile-first slide-out drawer with hamburger toggle, accordion submenu, and social links.

2. **Hero Section**:
   - Split layout with bold typography.
   - Headline: *"Build Smarter. Create Without Limits."* with animated text gradient.
   - Small glowing badge: *"Innovation • Technology • Creativity"*.
   - Call-to-action buttons (*"Explore Our Services"*, *"Discover Our Work"*).
   - Metrics bar (*99.9% Uptime SLA*, *0.8s Ultra-fast Response*, *100% Commitment*).
   - Abstract tech terminal mockup on the right with live animated sparkline chart, code simulation, and floating 3D status panels.
   - Animated mouse scroll indicator.

3. **Features Section ("Technology That Moves You Forward")**:
   - 4 premium feature cards (*Lightning Fast*, *Responsive Design*, *Scalable Solutions*, *Innovation First*).
   - Custom gradient icon containers, subtle glowing hover effect, and 3D mouse tilt.

4. **Services Section ("What We Do")**:
   - 4 detailed service cards (*Web Development*, *UI/UX Design*, *Digital Solutions*, *Technology Consulting*).
   - Tech stack tags, feature checklists, and interactive modal triggers (*"Explore Service"*).

5. **About / Why MainCrafts ("Turning Vision Into Digital Reality")**:
   - Two-column layout with company mission, value pillars, and craftsmanship narrative.
   - Highlighted statistics card with **animated number counters** that smoothly count up when scrolled into view:
     - **100%** Commitment
     - **99.4%** Innovative Thinking
     - **24/7** Future Ready

6. **Call to Action (CTA) Section ("Have an Idea? Let's Build It.")**:
   - High-impact visual banner with radial glow backdrops and floating shapes.
   - Direct trigger to start an inquiry.

7. **Contact Section & Interactive Form**:
   - Two-column contact hub with direct copyable email (`hello@maincrafts.tech`), studio location, and guaranteed response time.
   - Full interactive contact form with real-time field validation, active state loading spinner, and toast notification confirmation.

8. **Footer**:
   - Brand logo, description, live SLA status badge, quick links, service anchors, social links, copyright, and working modal triggers for Privacy Policy and Terms & Conditions.

9. **Global Utilities**:
   - Smooth Scroll-to-Top button that fades into view past 350px scroll depth.

## 💻 How to Run Locally

### Option 1: Using Python (Recommended)
Open your terminal in the project directory and run:
```bash
# Python 3
python3 -m http.server 8080
```
Then navigate to `http://localhost:8080/` in your browser.

### Option 2: Using Node / npx
```bash
npx serve .
```

### Option 3: Direct Browser Access
Double-click `index.html` or open it directly in Google Chrome, Safari, Firefox, or Microsoft Edge.
